## Farlands Reforged 0.7.0

**Push the Far Lands further out**: `farlandsStartX` and `farlandsStartZ` (or `/farlands set x|z <distance>`) now go past the classic 12,550,821, all the way to 30,000,000, the edge of the world. The land up to the new start is ordinary vanilla terrain, and the real Far Lands begin where you said. The world border stands at 29,999,984, so set a start just past it and the Far Lands sit behind the border: in sight, out of reach. Only newly generated chunks change.

With default settings, terrain is identical to 0.6.0.
